# Baseline — TTS service (before Change T cluster 1)

Recorded 2026-08-12 by cluster-1 implementer, before editing code. Source of
truth for what existed when Change T work began.

## Active files (tts_service)

- `src/tts/config.py` — `EngineConfig` / `ServerConfig` / `SecurityConfig`
  dataclasses; env `TTS_ENGINE` (default `none`), `TTS_MODEL`, `TTS_WEIGHTS_PATH`,
  `TTS_REF_AUDIO`, `TTS_DEVICE`, `TTS_SAMPLE_RATE`, `TTS_HOST/PORT`, `LOG_LEVEL`,
  `RUNTIME_ROOT`, `TTS_MAX_BODY_BYTES`, `TTS_MAX_CONCURRENT`, `TTS_REQUEST_TIMEOUT`,
  `TTS_AUTH_ENABLED/TOKEN/ADMIN_TOKEN`, `TTS_MAX_GPU_CONCURRENT`.
- `src/tts/engines/base.py` — `TTSEngine` ABC + registry + `ToneEngine` (deterministic
  sine fallback, 24 kHz) + `TTSRequest`/`AudioChunk`.
- `src/tts/engines/vieneu.py` — `VieNeuAdapter`, factory `Vieneu(mode=..., backbone_repo=..., device=...)`;
  v3-Turbo = 48 kHz, auto backend (ONNX/CPU vs PyTorch/GPU); tone-fallback only under
  `APP_ENV=dev` + `ALLOW_TTS_FALLBACK=1`.
- `src/tts/api/v1/routes/speech.py` — `POST /v1/speech` (StreamingResponse audio/pcm|wav,
  X-Audio-* headers), `GET /v1/speech/formats`, `GPUConcurrencyLimiter` gate.
- `src/tts/api/v1/routes/voices.py` — `GET /v1/voices` → `VoiceListResponse` with one
  "default" `VoiceInfo` from active engine.
- `src/tts/api/health.py` — `GET /health/live` (always ok), `GET /health/ready`
  (200 ready / 200 not_ready via `app.state.engine_ready`).
- `src/tts/api/security/` — bearer + scope auth (`tts.synthesis`, `tts.voices`;
  admin scopes for `admin` subject). Subjects: `service` / `admin`.
- `src/tts/api/exception_handlers.py` — envelope `{"error": {code, message}}`;
  engine error → 502 `engine_error`, unavailable → 503 `engine_unavailable`.
- `src/tts/bootstrap/app_factory.py` + `lifespan.py` — `app.state.engine`,
  `engine_ready`; lifespan builds engine from `load_engine_config()`.

## API contract fixtures

- `contracts/v1/openapi.json` — committed, generated by `scripts/contracts/generate.py`
  (deterministic, `sort_keys` + indent 2; health paths excluded; `/v1/*` only).
  Current paths: `/v1/speech`, `/v1/speech/formats`, `/v1/voices`.
- Drift gate: `tests/contract/test_tts_v1.py::test_contract_matches_built_app`
  compares `app.openapi()` (minus `/health*`) with the committed file;
  `test_contract_drift_tts.py` shells `scripts/contracts/check.py --scope tts`
  which ALSO checks backend contract (tts scope fans out to backend artifact).
- pytest addopts: unit runs by default; `tests/integration` + `tests/contract`
  run explicitly (per task instructions).
- Envelope error shape: `{"error": {"code": str, "message": str}}`.

## Docker entrypoint (to be replaced in cluster 8)

- `Dockerfile` + `entrypoint.sh` in `services/product/tts_service/`; currently starts
  the vLLM-Omni fork (`vllm serve` style) — stale v2-era runtime. Cluster 8 rewrites
  to boot the Python `tts_service` app with pinned VieNeu v3 Turbo.

## Config env currently active

- `TTS_ENGINE=none` default → `ToneEngine` (dev/CI); `TTS_ENGINE=vieneu` +
  `TTS_MODEL=pnnbao-ump/VieNeu-TTS-v3-Turbo` for real provider.
- v2-era defaults (`MODEL_ID=pnnbao-ump/VieNeu-TTS-v2`, `GPU_MEMORY_UTILIZATION`,
  vLLM-Omni options) live in Docker/entrypoint paths, not in `config.py`.

## Backend caller assumptions

- `services/product/backend_service/src/backend/application/clients/tts/self_hosted.py`:
  `SelfHostedTTSClient.synthesize()` → `POST {base}/v1/speech` with
  `{"text", "voice", "language", "response_format"}`; consumes raw audio
  (audio/pcm or audio/wav) + `X-Audio-*` headers. No vieneu imports.
- Change T keeps `/v1/speech` canonical (cluster 1) and adds `/v1/audio/speech`
  alias (same handler) per spec. New scheduler fields must be accepted with safe
  defaults; existing callers unaffected.
