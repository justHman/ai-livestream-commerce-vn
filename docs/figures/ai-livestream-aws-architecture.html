Primary traffic flows

1. Control plane (HTTPS) Viewers/SE → Cloudflare → ALB:443 → Backend:8800
Backend → RDS 5432 · Redis 6379 · SSM secrets · CloudWatch
2. Realtime pipeline (~300ms tick) Platform WS → Backend ChatQueue → Director decide → LLM SSE 8001 → TTS SSE 8002 → LiveKit audio · Avatar 8080 → LiveKit video
3. Media + deploy Viewers WebRTC UDP direct → LiveKit (bypass Cloudflare)
GitHub OIDC → Docker Hub push · ECS pull via IGW · GPU/TTS entrypoint aws s3 sync weights

AWS best practices applied

  • Public subnet + IGW for outbound (ECS public-subnet pattern) — no NAT cost
  • Isolation via Security Groups, not private-subnet tax
  • ALB for L7 routing / sticky WS; Cloudflare for edge DNS/DDoS
  • Fargate for stateless CPU; EC2 Spot only where GPU/stateful needed
  • Secrets in SSM SecureString; IAM task roles; OIDC CI/CD
  • Weights out-of-band on S3 (image stays small, Hub free public OK)
